# Technical documentation

## Input

An interface, module, operation or property whose implemented behavior must be
understood. User instructions belong in [user documentation](../user/README.md).

## Properties and state changes

Documentation does not grant execution authority or change feature defaults.
Historical checkpoints and architecture contracts remain retained at their new
archive paths; historical content is not silently rewritten as current behavior.
