# Artifact capture, manifests and reads

## Input

Finite declared members, immutable execution/definition/source bindings, retained creator ownership, independent source/custody/quota evidence and current export permission.

## Output

Sealed receipt/manifest, verified selected member bytes, or refusal with uncertain capacity retained.

## Functionality

Capture/read helpers execute in mandatory isolated containers. Private manifest assembly validates actual stored bytes and finite membership. Reader validation covers all siblings before returning one member. Production task-output attachment and user file delivery remain incomplete. A synthetic protocol receipt is not persisted-byte evidence.

## Properties and state changes

Reservation precedes writes. Seal/manifest/read acknowledgments are durable transitions. Failure withholds bytes/results; history and uncertain storage persist. Capture/read control protocols and grants remain separate even where lifecycle mechanics are shared.
